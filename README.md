# EPP-LE-BON-SAMARITAIN-Projet
Application pour gérér une école primaire autrement ....
1. Présentation générale
EPP Le Bon Samaritain Manager est une application web destinée à faciliter la gestion administrative, scolaire, pédagogique et financière d’un établissement d’enseignement primaire.
L’application doit centraliser les informations des élèves, les inscriptions, les classes, les matières, les composantes pédagogiques, les évaluations et les résultats scolaires.
L’objectif est de remplacer progressivement les procédures manuelles dispersées dans les cahiers, les feuilles Excel et les documents papier par une solution numérique organisée, fiable, sécurisée et facile à utiliser.
Le produit doit être conçu pour un établissement primaire ivoirien, en tenant compte de ses niveaux scolaires, de ses pratiques d’évaluation et de ses besoins administratifs.

3. Problématique
La gestion quotidienne d’une école primaire mobilise beaucoup de temps et de ressources. Les informations des élèves, les inscriptions, les classes, les notes, les bulletins et les paiements peuvent être dispersés entre plusieurs documents.
Cette organisation rend plus difficile la recherche d’informations, le suivi des résultats, le contrôle des inscriptions, la préparation des bulletins et la production de rapports fiables.
L’application doit donc centraliser les données, réduire les erreurs de saisie, simplifier les opérations répétitives et améliorer le suivi des élèves.

4. Objectifs du projet
3.1. Objectif général
Développer une application web complète de gestion d’une école primaire, utilisable par la direction et les personnels autorisés.
